# 🎬 台本A｜15秒・リーチ型「7年」

**狙い**：数字のギャップで止める。1秒目が勝負。

| 秒数 | 映像 | テロップ | 補足 |
|---|---|---|---|
| 0–2s | じゃがいもを掘り上げる手元アップ | **「この畑、7年かかりました。」** | 音源のみ |
| 2–5s | 痩せた土／石だらけの畝 | 「借りたときは、誰も作っていない土地でした」 | |
| 5–8s | 収穫量の少ないカゴ（再現でOK） | 「最初は、植えた量の2〜3倍しか穫れなかった」 | |
| 8–11s | イノシシに荒らされた跡／掘り返された土 | 「植えた3分の1を、イノシシに食べられた年も」 | ここで一度テンポを落とす |
| 11–14s | 今年のカゴいっぱいのじゃがいも | **「7年目。いちばん穫れました。」** | 音を大きく |
| 14–15s | 畑の引き画 | 「伊那谷より @kuma_farm」 | |

> 肥料をがっつり入れれば5〜7倍穫れる、という数字を入れるとさらに効きます（8sのテロップに一行足す）。

# 🎬 台本B｜30秒・ストーリー型「効率は、悪いです」★本命推奨

**狙い**：保存とコメントを取る。声入れ（ナレーション）推奨。
この家の「続ける理由」がいちばん素直に出る構成です。

**0–3s｜フック**
- 映像：チャイルドシート／抱っこ紐のまま軽トラに乗り込む
- テロップ：**「畑に、赤ちゃんを連れていきます。」**
- ナレ：「効率は、はっきり言って悪いです。」

**3–10s｜どれくらい悪いか**
- 映像：車窓から流れる山道 → 畑に着いて荷物を下ろす
- テロップ：「片道10分」「おむつ、着替え、お世話グッズ一式」
- ナレ：「車で片道10分。おむつも着替えも積んで、やっと着いて。そこから授乳に30分、40分。」

**10–17s｜ほとんど進まない**
- 映像：途中で止まった作業、置きっぱなしの鍬
- テロップ：「作業、ぜんぜん進みません」
- ナレ：「その日にやるつもりだったこと、半分も終わらない日もあります。」

**17–25s｜それでも**
- 映像：木陰で授乳しながら見上げた空 → 南アルプスの稜線 → 風に揺れる葉
- テロップ：**「でも。」**
- ナレ：「見上げると、空と南アルプスがあって。風の音と鳥の声を聞きながら、息子はそのまま寝てしまう。」

**25–30s｜締め**
- 映像：眠る子ども（顔は写さず、手や足元だけで十分）→ 畑の引き画
- テロップ：**「これができるの、あと1、2年だと思うから。」**
- ナレ：（無音でも成立します）

> 台本Bの強さは「効率が悪い」と先に認めていること。
> きれいごとから入らないので、同じ立場の人に刺さります。

# 🎬 台本C｜45秒・「3つの理由」リスト型

**0–3s**｜引き画＋テロップ：**「我が家が、野菜作りをやめない理由。」**

**① 3–15s｜味が、ぜんぜん違うから**
- 映像：じゃがいもを半分に割る断面アップ／蒸かしたてから湯気
- テロップ：「①肥料を入れすぎない、という選び方」
- ナレ：「肥料をたくさん入れれば、大きくてたくさん穫れます。でも早く傷んだり、中に黒い筋が入ったりする。うちは最小限。だから身がぎゅっと締まって、味が濃い。」

**② 15–30s｜畑が、勉強だから**
- 映像：3〜4枚の畑をそれぞれ短く／うまくいった畝と、ダメだった畝
- テロップ：「②同じ年は、ひとつもない」
- ナレ：「畑を3〜4枚借りていて、それぞれクセが違う。うまくいく年も、いかない年もある。天気しだいで毎年ちがう。畑って、ずっと勉強だなと思っています。」

**③ 30–40s｜暮らしの時間そのものだから**
- 映像：夫が畝立て／自分が芽かき・虫取り／子どもが手伝う
- テロップ：「③ふたりで、ちょっとずつ」
- ナレ：「畝立てと植え付けは夫。芽かきと虫取りと収穫は私。出産直後の植え付けは、夫がひとりで頑張ってくれました。」

**40–45s｜締め**
- テロップ：**「7年かけて、やっと安定しました。」** →「@kuma_farm」

## 🎥 撮っておきたいカット

**じゃがいも系（台本A・C用）**
- 掘り上げる手元アップ（土を払う動きが入ると◎）
- じゃがいもの断面（包丁で割る音を録る）
- カゴいっぱいの引き画（量が伝わる角度で）
- イノシシに荒らされた跡（**これは絶対に撮っておく価値があります**）
- 刈った草をじゃがいもに敷いているところ（対策の実例＝保存されます）

**子連れ・暮らし系（台本B用）**
- 軽トラに乗り込む／荷物を積むところ
- 車窓から流れる山と道
- 木陰のシート、置かれた鍬（＝作業が止まっている画）
- **下から見上げた空と南アルプス**（台本Bのクライマックス）
- 眠る子どもの手・足元だけ（顔なしで十分伝わります）

**夫婦の分担（台本C用）**
- 畝立て・植え付けをする夫の後ろ姿
- 芽かき・虫取りをする自分の手元

## 🎵 編集のコツ

- 音源は**歌詞なしのアコースティック／ピアノ系**。ナレーションと喧嘩しません
- 1カット2〜3秒。台本Bの「でも。」の前だけ、1拍だけ間を空けると効きます
- カバー（1枚目）：引き画＋短い文字だけ
  - A →「7年かかりました」
  - B →「畑に、赤ちゃんを連れていきます」
  - C →「野菜作りを続ける3つの理由」
- キャプション冒頭2行が命。上の3案はすべて2行で切れるよう作ってあります
- 顔出しなしで全部成立する構成にしてあります
